# Blanck Capital Brand & Logo Suite

Official vector wordmarks and typography specifications for **Blanck Capital LLC**. All `.svg` files use pure, self-contained `<path>` outlines with zero font dependencies and no icon mark, matching the live wordmark on [blanckcapital.com](https://blanckcapital.com/).

---

## Color Palette & Hex Codes

| Color Name | Hex Code | RGB | Usage |
| :--- | :--- | :--- | :--- |
| **Ink** (Dark Primary) | `#07080B` | `rgb(7, 8, 11)` | Dark backgrounds, primary wordmark on light |
| **Bone** (Light Primary) | `#EDEAE3` | `rgb(237, 234, 227)` | Light backgrounds, primary wordmark on dark |
| **Brass** (Gold Accent) | `#C8A96B` | `rgb(200, 169, 107)` | UI accents on dark backgrounds |
| **Brass Deep** | `#6E5626` | `rgb(110, 86, 38)` | UI accents on light backgrounds |
| **Pure White** | `#FFFFFF` | `rgb(255, 255, 255)` | Monochrome white wordmark |
| **Pure Black** | `#000000` | `rgb(0, 0, 0)` | Monochrome black wordmark |

---

## Typography Specifications

- **BLANCK**: **Archivo** (Sans-Serif), Weight 900 (Black), Width 125 (`font-variation-settings: "wdth" 125`), Uppercase, `-0.01em` tracking.
- **Capital**: **Bodoni Moda** (Serif Italic), Weight 400, Italic.

## Included Vector Files (`/logos/`)

### 1. Primary Horizontal Wordmarks (Matches Website Header)
- [`blanck-capital-logo-horizontal-dark.svg`](./blanck-capital-logo-horizontal-dark.svg): Bone (`#EDEAE3`) wordmark on a transparent background for dark surfaces, decks, and headers.
- [`blanck-capital-logo-dark-bg.svg`](./blanck-capital-logo-dark-bg.svg): Bone (`#EDEAE3`) wordmark locked up on solid Ink (`#07080B`) background.
- [`blanck-capital-logo-horizontal-light.svg`](./blanck-capital-logo-horizontal-light.svg): Ink (`#07080B`) wordmark on a transparent background for white documents, letterheads, and light layouts.

### 2. Stacked Wordmarks (Matches Square Favicon Lockup)
- [`blanck-capital-logo-stacked-dark.svg`](./blanck-capital-logo-stacked-dark.svg): Centered two-line Bone (`#EDEAE3`) wordmark on a transparent background.
- [`blanck-capital-logo-stacked-light.svg`](./blanck-capital-logo-stacked-light.svg): Centered two-line Ink (`#07080B`) wordmark on a transparent background.

### 3. Single-Color Monochrome Wordmarks
- [`blanck-capital-monochrome-white.svg`](./blanck-capital-monochrome-white.svg): 100% Solid White (`#FFFFFF`) horizontal wordmark on a transparent background.
- [`blanck-capital-monochrome-black.svg`](./blanck-capital-monochrome-black.svg): 100% Solid Black (`#000000`) horizontal wordmark on a transparent background.
