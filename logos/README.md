## 🔤 Typography Specifications

- **BLANCK**: **Archivo** (Sans-Serif), Font Weight 900 (Black), Width Setting 125 (`font-variation-settings: "wdth" 125`), All-Caps.
- **Capital**: **Bodoni Moda** (Serif Italic), Font Weight 400, Italic.

## 👕 Merch & Printing Guidelines

1. **Vector Scalability:** All `.svg` files are true scalable vector graphics. They can be scaled infinitely to any DPI (300+ DPI) for high-resolution printing without loss of quality.
2. **Embroidery:** Use `blanck-capital-icon-gold.svg` or `blanck-capital-monochrome-white.svg` for hat, polo, or jacket embroidery.
3. **Apparel Screen Printing:** Use stacked or horizontal SVGs directly in Adobe Illustrator, Photoshop, Figma, or Canva.
4. **Metal / Leather Engraving:** Use `blanck-capital-monochrome-black.svg` for clean vector toolpaths.
